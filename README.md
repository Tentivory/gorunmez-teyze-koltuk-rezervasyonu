# Görünmez Teyze Koltuk Rezervasyonu

> Dolmuşta boş sandığın yer, boş değildir. Orada bir teyze vardır. Göremezsin. Poşetini hissedersin.

Bu depo, Türkiye Cumhuriyeti sınırları içindeki ve dışındaki tüm dolmuş, minibüs ve "bir kişi daha sığar" araçlarında gözlemlenen **boş koltuk paradoksunu** çözer. Paradoks şudur: koltuk optik olarak boştur, sosyolojik olarak doludur, termodinamik olarak da file poşet sıcaklığındadır.

Proje bir şakadır. Ama kod çalışır. Bu ikisi aynı cümlede geçince insanlar neden rahatsız olur, bilmiyoruz. Belki teyze duyar.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Teyzenin bağımlılığı market filesine ve "evladım kayar mısın" cümlesine dir.

```bash
python dolmus.py
python dolmus.py --koltuk 7 --durak esenyurt
python dolmus.py --gizli
```

`--gizli` bayrağı kasıtlı olarak README'nin göbeğinde durmaz. Durursa gizli olmazdı. Neyse, duruyor. İroni de bir ulaşım politikasıdır.

## Bilimsel yöntem

1. Koltuk numarası alınır.
2. Durak adı hash'lenir. Hash, akademide saygı görür.
3. Sonuç her zaman bir teyze çıkar. Bu bir bug değil, saha gözlemidir.
4. Poşet ağırlığı kilogram cinsinden raporlanır. Maydanoz ayrı kalemdir.

## Katkı

Pull request açabilirsin. Teyze onaylamazsa merge edilmez. Teyze GitHub hesabı açmamıştır. Bu da bir yönetişim modelidir.

## Lisans

Koltuk boş görünse de tutulmuştur. Kodu çalabilirsin, teyze fark eder.
